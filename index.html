Preparación del texto

Anonimizador de textos

Detecta localmente fechas, números de identificación o de expediente y montos, y los reemplaza por etiquetas reversibles.

La detección automática no reemplaza la revisión humana. La herramienta permite generar un prompt que solicita a un modelo de lenguaje la identificación y sustitución de datos adicionales. Este segundo paso debe evaluarse con especial cuidado: aunque las fechas, los números y los montos ya hayan sido reemplazados localmente, los datos que permanecen visibles en el texto se compartirán con el servicio de IA utilizado. .

Usar en el navegador Descargar para uso local
Uso local: la herramienta puede utilizarse desde esta página o descargarse y abrirse como archivo HTML en una computadora. La detección automática y la generación del archivo JSON se realizan en el navegador.
